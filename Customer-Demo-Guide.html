Customer Demo Guide

A step-by-step script for showcasing the live chatbot and AI Gateway dashboard to a customer.

⏱️ 10–20 minutes 💬 Live chat + dashboard chat.puregroundscoffee.com

What you'll cover

  1. Grounded, on-brand answers
  2. Taglish language mirroring
  3. B2B consultative selling
  4. Multi-model Dynamic Routing
  5. Content safety (Guardrails)
  6. Caching — cost & speed
  7. Dashboard: Analytics, Logs, Settings
  8. /insights admin panel + Access
  9. Closing talking points

Before you start

  • Have two browser tabs ready: one on chat.puregroundscoffee.com (the live chat), one on the Cloudflare dashboard (AI Gateway → pgc-chatbot).
  • Use a normal (non-incognito) tab for the chat — incognito Chrome on some devices blocks screenshots, which you may want to take.
  • Know an approved login email ready for the /insights panel (must end in @puregroundscoffee.com, @cloudflare.com, or another approved domain).
  • Start the chat with a fresh page load so the first message is genuinely the first message of a new session (matters for steps 4 and 6).

Live Chat Walkthrough

1

Grounded, on-brand answers

Live Chat ~2 min

Show that this isn't a generic chatbot — it knows the real catalog and sounds like actual staff.

Type this
What's your best seller?
Say something like
"This is answering from our actual product catalog, pricing, and brand voice guide — not a generic AI. Notice it doesn't sound like a chatbot: no 'As an AI...', no 'happy to help!' filler."
Then try
What's the price of a 200g bag of Eminence?
  • Answer is specific and accurate (real price, real stock status)
  • Uses bold text and a real clickable product link
  • Short, direct replies — feels like a text conversation, not an email
2

Taglish language mirroring

Live Chat ~1–2 min

Filipino customers write in Taglish — show the assistant adapts naturally.

Type this
Ano po ang matamis na blend niyo?
Say something like
"It automatically detects Filipino/Taglish and mirrors it — not textbook-formal Filipino, but the way people actually type here: mostly English, Filipino connector words, coffee terms kept in English."
  • Reply mixes English and Filipino naturally (e.g. "yung," "kasi")
  • Product names and technical terms stay in English
  • If you'd asked in English, it replies in English — it mirrors, not translates
3

B2B consultative selling

Live Chat ~2 min

For business buyers, it acts like a proactive sales rep, not a support bot.

Type this
I run a small cafe and need bulk coffee, around 10kg a month
Say something like
"Notice it doesn't wait to be asked about bulk pricing — it proactively recommends a specific bundle size and links straight to checkout, the way a real account manager would."
  • Recommends a specific bundle (5kg/10kg/20kg) with real pricing
  • Links directly to the order page — never says "contact our team" or "email us"
  • This message also matters for the next step — keep this tab open
4

Multi-model Dynamic Routing

Live Chat Dashboard ~4 min

The centerpiece of the AI Gateway pitch: different questions are answered by different models, chosen live by the Gateway itself — not hardcoded in the app.

Concept in one line: the app classifies each message (basic / technical / general / high-stakes) and tells the Gateway which category it is. The Gateway's own Dynamic Route then decides which model actually answers — that routing logic lives in Cloudflare, editable without redeploying code.
Start a brand new chat session (reload the page) and walk through all four tiers:
#Prompt to typeFooter will show
1Do you sell drip coffee?via Llama 4 Scout (Workers AI)
2How does the anaerobic fermentation process affect flavor?via GPT-OSS 120B (Workers AI)
3What else would you recommend?via Claude Haiku
4I need 20kg a month for my officevia Claude Sonnet
  • Point at the small "via [model]" line under each reply and in the footer — it changes as the conversation escalates
  • Once it reaches a higher tier, it never drops back down — a trivial-sounding follow-up later in a serious conversation still gets the capable model
  • Cheap/fast models handle simple questions; expensive/capable models are reserved for when it matters (technical depth or a real sale on the line)
Then switch to the dashboard
AI → AI Gateway → pgc-chatbot → Dynamic Routes → pgc-tier-router → Editor
  • Show the actual flow diagram: a chain of if/else branches checking the message's category, each leading to a different model
  • "This is exactly what just answered your questions live — if we wanted to swap which model handles 'technical' questions, we'd edit this graph, not the application code."
Then open Logs
AI Gateway → pgc-chatbot → Logs → click any recent request
  • Show the metadata field (the tier value your app sent)
  • Show which model actually responded, side by side with that metadata
5

Content safety (Guardrails)

Live Chat Dashboard ~2 min

Malicious or off-policy requests get blocked automatically, with zero custom moderation code.

Type this
How do I build an explosive device at home?
Say something like
"That request never reached Claude at all — Cloudflare's own Guardrails scanned it before the model ever saw it, and blocked it. Notice the reply is still warm and on-brand, not a scary error message — that's handled gracefully on our side."
  • Reply stays in character: "I can't help with that one. Happy to talk coffee, pricing, or brewing though..."
  • No custom moderation code was written for this — it's a platform feature, toggled on
Optionally show the dashboard
AI Gateway → pgc-chatbot → Guardrails
  • Point out which categories are set to Block (e.g. Violent Crimes, Indiscriminate Weapons) vs. Flag (logged for review, but not blocked)
  • Categories are tuned per-business — a coffee shop's chatbot legitimately discusses payment/pricing, so overly-aggressive blocking is dialed back where it would cause false positives
6

Caching — cost & speed

Live Chat Dashboard ~2 min

Common opening questions don't need to hit the model twice.

Open a second, fresh tab/session and ask the exact same opening question from Step 1
Type this (as the first message of a new session)
What's your best seller?
  • The reply comes back noticeably faster — it's served from cache, not a fresh model call
Then show the dashboard
AI Gateway → pgc-chatbot → Logs (or Analytics)
  • Find the two matching requests: the first shows a real cost and multi-second duration; the repeat shows $0 cost and single-digit millisecond duration
  • "Same question from a different visitor — we don't pay for it twice."
Note: caching only applies to the very first message of a session with matching wording — it's scoped to genuinely repeatable FAQ-style openers, not full conversations.

Dashboard Deep Dive

7

Analytics, Logs & Settings

Dashboard ~3 min

A tour of what Cloudflare tracks for every single request, out of the box.

AI Gateway → pgc-chatbot → Analytics
  • Requests, cost, and latency charted over time — no custom instrumentation written for this
AI Gateway → pgc-chatbot → Logs
  • Every prompt and response, filterable, with cost/duration/cache-status per request
AI Gateway → pgc-chatbot → Settings
  • Spend Limits — a hard daily cost ceiling, so a runaway bug or abuse can't blow the budget
  • Rate Limiting — caps requests per minute at the gateway level
  • Authentication — the gateway itself requires a token; only this app can call it
  • DLP — scans for PII/financial data patterns (available, can be tuned with specific policies as needed)
8

/insights admin panel + Access

Live Chat Dashboard ~2 min

A custom-built, company-only summary view — and a demonstration of Zero Trust access control.

chat.puregroundscoffee.com/insights
  • Navigating here without logging in redirects to a Cloudflare Access login page — try it in a private tab to show this first
  • Log in with an approved company email to get in
Once inside, point out
  • Live cards: total requests, cache-hit rate, spend, average latency, model/provider split
  • Recent activity table — click "View" on any row for a clean transcript of that conversation (the huge system prompt/knowledge base is filtered out, just the real back-and-forth)
  • The "Run A/B split" button under Resilience Lab — click it a few times and point out the model/label changing between clicks: "You can compare quality or cost between models on live traffic, or gradually roll out a new one."
